About

I started programming by trying to fix things that were broken. That turned into building things from scratch — websites at first, then full-stack applications, then trading systems and automation tools.

Today I run 45Creatives, a web studio where I design and build websites, dashboards, and brand systems for clients. Independently, I work on projects like algorithmic trading systems in MQL5 and Python, a billing platform that integrates M-Pesa and Mikrotik, and various automation tools.

I'm most interested in work that involves solving a real problem with code — whether that's a client website that needs to convert visitors, a backend system that needs to handle payments reliably, or a data pipeline that needs to process market data in real time.
